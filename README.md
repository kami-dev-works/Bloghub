# Bloghub
BlogHub is a full-stack content platform with news/blog publishing and a services marketplace. Built with Astro 5 SSR + React 18 SPA + Express/MongoDB, it features comprehensive SEO (SSR JSON-LD, sitemaps, RSS, hreflang, IndexNow), theme customization, multilingual support, and an admin dashboard for blogs, services, users, sliders, and settings.
